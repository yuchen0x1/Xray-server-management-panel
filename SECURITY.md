# Security policy

Security fixes go to the current stable release of this fork. Check the [latest stable release](https://github.com/yuchen0x1/Xray-server-management-panel/releases/latest).

Report vulnerabilities with [GitHub private vulnerability reporting](https://github.com/yuchen0x1/Xray-server-management-panel/security/advisories/new). Include the affected version, deployment type, impact and relevant redacted logs. Keep credentials, subscription links, private keys and database copies out of the report.

Release archive verification and Linux upgrade requirements are documented in the [update guide](docs/AUTO_UPDATE.md).
